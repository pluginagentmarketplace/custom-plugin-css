# 🚀 Getting Started with Developer Roadmap Plugin

Welcome! This guide will help you get the most out of the plugin in your first 30 minutes.

## Step 1: Installation (2 minutes)

### Option A: Simple Command
```bash
claude add developer-roadmap-plugin
```

### Option B: Load Locally
```bash
claude load ./developer-roadmap-plugin
```

✅ **Done!** Plugin is now active in Claude Code.

## Step 2: Explore Your Options (5 minutes)

Start by understanding what you can do:

```bash
/learn
```

This shows all 71 available roles across different specializations.

Or browse the agents:
```bash
/browse-agent
```

This explains the 7 expert agents and their focus areas.

## Step 3: Choose Your Path (5 minutes)

### I'm Starting Out
If you're new to development:
```bash
/learn frontend
# or
/learn backend
# or
/learn fullstack
```

### I Know My Goal
If you know what you want to specialize in:
```bash
/learn react           # Frontend React
/learn devops          # DevOps & Infrastructure
/learn data-engineer   # Data Engineering
/learn system-design   # Architecture
```

### I'm Unsure
Take a quick assessment:
```bash
/assess quick
```

This helps identify your strengths and gaps.

## Step 4: Understand Your Agent (5 minutes)

Once you know your path, explore the assigned agent:

```bash
/browse-agent 3
# Detailed explanation of the Frameworks & Databases Agent
```

This shows:
- Expert focus areas
- Key skills you'll master
- Best practices
- Real-world applications
- Time commitment

## Step 5: Find Your First Project (3 minutes)

Start building with a hands-on project:

```bash
/projects [agent-number] beginner
# Example: /projects agent-1 beginner
```

Choose a project that interests you. Build it, deploy it, add to your portfolio.

## 📚 How to Use Each Component

### /learn Command
Shows all 71 roles and starts your learning path.

**Use when:**
- You want to explore a new career path
- Starting from scratch
- Need structured guidance
- Want to know recommended sequence

### /browse-agent Command
Explores one of 7 specialized agents.

**Use when:**
- Understanding what topics agent covers
- Deciding between specializations
- Getting expert context
- Finding time estimates
- Choosing team members

### /assess Command
Evaluates your current knowledge.

**Use when:**
- Before starting (identify gaps)
- After projects (validate learning)
- For interviews (preparation)
- Career transitions (find strengths)
- Mentoring (understand mentee level)

### /projects Command
Finds 100+ hands-on projects.

**Use when:**
- Ready to build
- Need portfolio pieces
- Want practical experience
- Learning by doing
- Interview preparation

## 💡 Pro Tips

### 1. Don't Skip Fundamentals
Even if experienced, review fundamentals. They reveal gaps.

### 2. Build Real Things
Better to build 1 complete project than 5 incomplete ones.

### 3. Deploy Everything
Put projects on GitHub, Netlify, Heroku. Real portfolios matter.

### 4. Read All the Code
Don't just copy-paste. Understand every line.

### 5. Create Personal Variations
Don't just follow tutorials. Add your own features.

### 6. Document Your Learning
Blog posts, README files, commit messages = better learning.

### 7. Join Communities
Find others learning same path. Network and grow together.

### 8. Reassess Regularly
Run `/assess` every month to track progress.
