# /assess - Knowledge Assessment

Evaluate your skills and knowledge across different developer roles and technologies.

## Usage

```
/assess [role-or-agent]
/assess quick
/assess detailed
```

## Assessment Methods

### Quick Assessment (5-10 minutes)
Quick self-evaluation across key concepts.

```
/assess quick
```

**Covers:**
- Familiarity with tools/languages
- Practical experience
- Conceptual understanding
- Self-rating scale

---

### Detailed Assessment (20-30 minutes)
Comprehensive skill evaluation with specific questions.

```
/assess detailed
```

**Covers:**
- Foundational knowledge
- Intermediate concepts
- Advanced topics
- Real-world scenarios
- Problem-solving ability

---

### Role-Specific Assessment
Assess your readiness for a specific role.

```
/assess frontend
/assess fullstack
/assess devops
/assess data-engineer
/assess product-manager
```

## Assessment Scoring

### Knowledge Levels

| Level | Description | Score |
|-------|-------------|-------|
| **Beginner** | Familiar with basics, needs guidance | 1-2 |
| **Intermediate** | Practical experience, solve common problems | 2-3 |
| **Advanced** | Deep expertise, solve complex problems | 3-4 |
| **Expert** | Master level, guide others | 4-5 |

### Readiness Scale

| Score | Readiness | Recommendation |
|-------|-----------|-----------------|
| 0-1 | Not Ready | Focus on fundamentals |
| 1-2 | Foundation | Start learning path |
| 2-3 | Ready | Entry-level roles |
| 3-4 | Strong | Mid-level roles |
| 4-5 | Expert | Senior roles |

## Recommended Assessment Pathways

### For Career Changers
1. `/assess quick` - Initial check
2. `/assess fundamentals` - Foundation skills
3. `/assess [target-role]` - Specific path

### For Job Preparation
1. `/assess detailed` - Full evaluation
2. `/assess [target-role]` - Role-specific
3. **Focus on weak areas** before interviews

### For Learning Tracking
1. Initial assessment at start
2. Periodic `/assess [agent-number]`
3. Track progress over time

### For Mentoring
1. Mentee runs assessment
2. Review results together
3. Create personalized learning plan

---

## Using Assessment Results

### Identify Gaps
- Focus on low-scoring areas
- Find targeted learning resources
- Build specific projects

### Plan Learning Path
- Start with weak fundamentals
- Progress to intermediate skills
- Move to advanced topics

### Set Goals
- Near-term: Fill knowledge gaps
- Mid-term: Master core concepts
- Long-term: Become expert

### Track Progress
- Retest periodically
- Celebrate improvements
- Adjust learning plan
