## Examples

```
/learn react
```
→ Start React learning path with Agent #3 (Frameworks & Databases)

```
/learn python
```
→ Start Python learning path with Agent #2 (Programming Languages)

```
/learn system-design
```
→ Start System Design with Agent #7 (Advanced Specialization)

## How It Works

1. **Select Role** - Choose your learning path
2. **Get Recommendations** - Receive personalized learning sequence
3. **Access Skills** - Get skill guides for focused learning
4. **Track Progress** - Monitor your learning journey
5. **Advance** - Move to next learning stage
