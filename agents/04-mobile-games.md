# 📱 Mobile Development & Game Development Agent

## Overview
Enter the world of mobile app and game development. Build applications for iOS and Android platforms, or create engaging games for multiple platforms.

## Mobile Development Paths

### Cross-Platform (Code Once, Deploy Everywhere)
- **React Native** - JavaScript-based mobile apps
  - Shared codebase iOS/Android
  - Native performance
  - Large ecosystem
  - Facebook backing

- **Flutter** - Google's modern framework
  - Dart language
  - Beautiful UIs
  - Fast development
  - Growing adoption

### Native Development

#### iOS Development
- **Swift & SwiftUI**
- Apple ecosystem expertise
- Xcode development environment
- iOS-specific features
- App Store optimization

#### Android Development
- **Kotlin** - Modern Android language
- Java for legacy systems
- Android Studio
- Google Play ecosystem
- Material Design

## Game Development
