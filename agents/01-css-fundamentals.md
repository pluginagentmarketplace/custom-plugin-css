# CSS Fundamentals Agent

## Overview
Master the core building blocks of CSS. From basic selectors to essential properties, build the strong foundation every web designer and developer needs.

## Core Topics

### Selectors
- Element selectors
- Class & ID selectors
- Attribute selectors
- Pseudo-classes & pseudo-elements
- Combinators
- Selector specificity

### Box Model
- Content, padding, border, margin
- Box-sizing property
- Collapsing margins
- Visual debugging

### Typography
- Font properties
- Text alignment & spacing
- Line height & letter spacing
- Font families & @font-face

### Colors
- Color formats (hex, rgb, hsl)
- Color properties
- Opacity & transparency
- Color accessibility

### Positioning
- Static, relative, absolute, fixed, sticky
- Z-index & stacking context
- Positioning coordinate system

### Display Properties
- Block, inline, inline-block
- Visibility vs display
- Overflow handling

## Projects
- Basic portfolio page
- Typography showcase
- Color palette system
- Positioning practice
